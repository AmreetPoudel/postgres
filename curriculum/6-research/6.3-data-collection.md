## pg_stat_statements — The Most Important Extension

Enables per-query profiling. Essential for both research and production.

```sql
-- Enable in postgresql.conf (requires restart):
-- shared_preload_libraries = 'pg_stat_statements'

-- After restart:
CREATE EXTENSION pg_stat_statements;

-- Top queries by total time spent
SELECT
    round(total_exec_time::numeric, 2) AS total_ms,
    calls,
    round(mean_exec_time::numeric, 2) AS avg_ms,
    round(stddev_exec_time::numeric, 2) AS stddev_ms,
    round(min_exec_time::numeric, 2) AS min_ms,
    round(max_exec_time::numeric, 2) AS max_ms,
    rows,
    shared_blks_hit,
    shared_blks_read,
    temp_blks_written,
    left(query, 100) AS query
FROM pg_stat_statements
ORDER BY total_exec_time DESC
LIMIT 20;

-- Reset between runs (critical for clean experiments)
SELECT pg_stat_statements_reset();
```

## Collecting Time-Series Metrics

For "how did performance change over time during a benchmark" — collect snapshots:

```bash
#!/bin/bash
# snapshot_stats.sh
# Run this in the background during a benchmark

DB=${1:-pgbench_db}
INTERVAL=10
OUT="metrics_$(date +%Y%m%d_%H%M%S).csv"

echo "ts,xact_commit,blks_hit,blks_read,hit_rate,temp_files,checkpoints_req,buffers_backend" \
    > "$OUT"

while true; do
    psql -d "$DB" -t -A -F',' -c "
        SELECT
            now()::text,
            xact_commit,
            blks_hit,
            blks_read,
            round(blks_hit::numeric/nullif(blks_hit+blks_read,0)*100,2),
            temp_files,
            (SELECT checkpoints_req FROM pg_stat_bgwriter),
            (SELECT buffers_backend FROM pg_stat_bgwriter)
        FROM pg_stat_database WHERE datname='$DB';" >> "$OUT"
    sleep "$INTERVAL"
done
```

Run with: `./snapshot_stats.sh pgbench_db &`

## Useful pg_stat_* Views for Research

### Cache hit rate per table

```sql
SELECT
    relname,
    heap_blks_read                    AS disk_reads,
    heap_blks_hit                     AS cache_hits,
    round(heap_blks_hit::numeric /
          nullif(heap_blks_hit + heap_blks_read, 0) * 100, 2) AS hit_rate,
    idx_blks_read                     AS idx_disk_reads,
    idx_blks_hit                      AS idx_cache_hits
FROM pg_statio_user_tables
ORDER BY heap_blks_read DESC
LIMIT 20;
```

### Index scan efficiency

```sql
SELECT
    relname       AS table,
    indexrelname  AS index,
    idx_scan,
    idx_tup_read,
    idx_tup_fetch,
    round(idx_tup_fetch::numeric / nullif(idx_tup_read,0) * 100, 2) AS fetch_pct
FROM pg_stat_user_indexes
ORDER BY idx_scan DESC
LIMIT 20;
```

### Checkpoint and bgwriter health

```sql
SELECT
    checkpoints_timed,
    checkpoints_req,
    round(checkpoints_req::numeric /
          nullif(checkpoints_timed + checkpoints_req, 0) * 100, 1) AS pct_forced,
    checkpoint_write_time / 1000.0  AS write_sec,
    checkpoint_sync_time  / 1000.0  AS sync_sec,
    buffers_checkpoint,
    buffers_clean,
    buffers_backend,   -- should be a small share of all writes
    maxwritten_clean   -- bgwriter hitting its rate limit
FROM pg_stat_bgwriter;
```

### WAL generation rate

```sql
-- Cumulative WAL counters (PG14+): records, full-page images, bytes.
-- Snapshot them before and after a run and subtract.
SELECT wal_records, wal_fpi, wal_bytes, wal_buffers_full, stats_reset
FROM pg_stat_wal;

-- Or sample the WAL position twice, 60 seconds apart (psql):
SELECT pg_current_wal_lsn() AS lsn1 \gset
SELECT pg_sleep(60);
SELECT pg_size_pretty(pg_wal_lsn_diff(pg_current_wal_lsn(), :'lsn1') / 60) AS wal_per_second;
```

`wal_fpi` is the key number for checkpoint experiments: after every checkpoint, the first change to each page logs a full 8KB image of it.

### I/O by process type (PG16+)

```sql
-- Who reads and writes, and in what context: client backends vs checkpointer
-- vs bgwriter vs autovacuum, normal vs bulk operations.
-- Snapshot and subtract, or reset first with: SELECT pg_stat_reset_shared('io');
SELECT backend_type, object, context, reads, writes, extends, hits, evictions
FROM pg_stat_io
WHERE reads > 0 OR writes > 0
ORDER BY writes DESC NULLS LAST;
```

### Lock contention (for concurrency experiments)

```sql
SELECT
    wait_event_type,
    wait_event,
    count(*) AS sessions_waiting
FROM pg_stat_activity
WHERE wait_event IS NOT NULL
  AND state = 'active'          -- skip idle sessions waiting on ClientRead
GROUP BY wait_event_type, wait_event
ORDER BY sessions_waiting DESC;
```

## OS-Level Metrics to Collect

During a benchmark, always capture:

```bash
# I/O stats (per device, 1-second intervals)
iostat -xm 1 > "$OUTDIR/iostat.txt" &     # -m: throughput in MB/s
IOSTAT_PID=$!

# CPU and memory
vmstat 1 > "$OUTDIR/vmstat.txt" &
VMSTAT_PID=$!

# Run your benchmark...

# Stop collectors
kill $IOSTAT_PID $VMSTAT_PID
```

**Key iostat fields:**
- `%util`: Device utilization. Near 100% = saturated disk.
- `r_await` / `w_await`: Average read/write latency in ms. High = disk is a bottleneck.
- `rMB/s` / `wMB/s`: Throughput.

**Key vmstat fields:**
- `si` / `so`: Swap in/out. Any non-zero value = swapping = problem.
- `wa`: CPU waiting for I/O. High value = I/O bottleneck.

## Analyzing Results with Python

```python
#!/usr/bin/env python3
# analyze.py

import re
import statistics
import matplotlib.pyplot as plt

def parse_tps(filename):
    """Pull TPS value from pgbench output file."""
    tps_values = []
    with open(filename) as f:
        for line in f:
            # Match lines like: tps = 761.480 (without initial connection time)
            m = re.search(r'tps = ([\d.]+) \(without', line)
            if m:
                tps_values.append(float(m.group(1)))
    return tps_values

def parse_latency_avg(filename):
    """Pull average latency from pgbench output."""
    with open(filename) as f:
        for line in f:
            m = re.search(r'latency average = ([\d.]+) ms', line)
            if m:
                return float(m.group(1))
    return None

# ── Experiment 1: shared_buffers ──────────────────────────────────────────────
configs = ['1GB', '2GB', '4GB', '8GB', '12GB', '16GB']
tps_per_config = []

for size in configs:
    fname = f"/research/experiments/shared_buffers_{size}.txt"
    readings = parse_tps(fname)
    tps_per_config.append(readings)
    mean = statistics.mean(readings)
    std  = statistics.stdev(readings) if len(readings) > 1 else 0
    print(f"shared_buffers={size:5s}: {mean:7.1f} TPS ± {std:.1f}")

# Plot
means   = [statistics.mean(r) for r in tps_per_config]
stddevs = [statistics.stdev(r) if len(r) > 1 else 0 for r in tps_per_config]

plt.figure(figsize=(10, 5))
plt.errorbar(configs, means, yerr=stddevs, fmt='o-', capsize=5, linewidth=2)
plt.xlabel('shared_buffers value')
plt.ylabel('TPS (higher = better)')
plt.title('TPS vs shared_buffers — Read-Only Workload, pgbench scale=500')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('/research/paper/figures/shared_buffers_tps.png', dpi=300)
print("Figure saved.")
```

```
│       └── ...
├── paper/
│   ├── figures/

```
